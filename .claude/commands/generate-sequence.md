# Generate Sequence Command

Generate a personalized email sequence for a specific prospect using Claude's reasoning + web research.

**Skill reference**: Follow `.claude/skills/api-automation/SKILL.md` for all API calls.

## Workflow

### Step 1: Authenticate and gather prospect data

Authenticate via curl:

```bash
BASE="${ABM_BASE_URL:-https://abm.tecnociminnova.com}"
SLUG="${ABM_TENANT_SLUG:-tecnocim}"
TOKEN=$(curl -s -X POST "${BASE}/api/auth/login" \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"${ABM_EMAIL}\",\"password\":\"${ABM_PASSWORD}\",\"tenant_slug\":\"${SLUG}\"}" \
  | node -e "let d='';process.stdin.on('data',c=>d+=c);process.stdin.on('end',()=>{try{const r=JSON.parse(d);process.stdout.write(r.data?.token||'')}catch(e){}})")
```

If `ABM_EMAIL` or `ABM_PASSWORD` are not set, ask the user via AskUserQuestion.

Then fetch prospect data via curl:

```bash
# Search by email, name, or UUID
PROSPECT_DATA=$(curl -s "${BASE}/api/prospects?search=${IDENTIFIER}&limit=5" \
  -H "Authorization: Bearer ${TOKEN}")
```

Parse the response. If found, extract: prospect details, enrichment_data, company info, tags.

If the prospect is NOT in the platform (e.g., just a company name):
- Use WebSearch to find basic company info
- Use the **prospect-enricher** agent to enrich the company data

### Step 2: Research the company

Use the **email-generator** agent with:
- Prospect data (enriched)
- Campaign context from the user
- Tenant context (Tecnocim defaults unless specified)
- Sequence type (branched by default)

The email-generator agent will:
1. WebSearch recent news about the company
2. Generate personalized emails using enrichment + news
3. Return JSON with steps

### Step 3: Present for review

Show the user:
- Prospect summary (name, company, sector, city)
- Each email: step number, subject, body preview (first 100 chars)
- Branching logic (if branched): condition nodes and paths
- ICP score if available

Ask: "Do you want to save this sequence to the platform?"

### Step 4: Save to platform via curl

If the user approves:

```bash
# 1. Create sequence
SEQ_RESULT=$(curl -s -X POST "${BASE}/api/sequences" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sequence for COMPANY_NAME",
    "campaign_id": "CAMPAIGN_ID_IF_EXISTS",
    "from_email": "alfons@tecnocim.com",
    "from_name": "Alfons Marques",
    "reply_to": "alfons@tecnocim.com",
    "send_window": {"days":[1,2,3,4,5],"start_hour":9,"end_hour":17,"timezone":"Europe/Madrid"},
    "settings": {"stop_on_reply":true,"stop_on_bounce":true,"daily_limit":25}
  }')
SEQ_ID=$(echo "$SEQ_RESULT" | node -e "let d='';process.stdin.on('data',c=>d+=c);process.stdin.on('end',()=>{const r=JSON.parse(d);process.stdout.write(r.data?.id||r.data?.sequence?.id||'')})")

# 2. Add steps
curl -s -X POST "${BASE}/api/sequences/${SEQ_ID}/steps" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"steps": [... generated steps JSON ...]}'

# 3. Wire branching (if branched type)
# Get step IDs from the steps response, then wire condition nodes
curl -s -X POST "${BASE}/api/sequences/${SEQ_ID}/wire-steps" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"wiring": [{"step_id":"CONDITION_UUID","yes_next_step_id":"YES_UUID","no_next_step_id":"NO_UUID"}]}'

# 4. Enroll the prospect (if prospect exists in platform)
curl -s -X POST "${BASE}/api/sequences/${SEQ_ID}/enroll" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"prospect_ids": ["PROSPECT_UUID"]}'
```

Report: sequence ID, number of steps, enrollment status.

If not approved:
- Ask what to change
- Re-generate specific steps

## Example Usage

```
/generate-sequence "Aceros Martinez S.L." "Formacion IA para industria metalurgica" branched
/generate-sequence "info@acerosmartinez.es" "Consultoria innovacion" linear
/generate-sequence "abc-123-uuid" "AI training for manufacturers"
```

## Notes

- The sequence is NOT automatically activated -- it stays in "draft" status
- Emails are generated by Claude (not Gemini) for maximum quality
- Each email is personalized with real data from web research
- Branched sequences include condition nodes for opened/clicked behavior
